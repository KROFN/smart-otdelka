# Smart Otdelka

Portfolio landing page for a renovation and finishing services concept.

> **Status:** Portfolio frontend project.  
> Created as a visual landing page concept for a service business scenario.

## What it is

Smart Otdelka is a frontend landing page for renovation and finishing services. The project focuses on clear service presentation, visual structure, responsive layout and a polished portfolio-style interface.

## What it shows

- service landing page structure
- responsive React/Vite implementation
- animation and interaction polish
- visual portfolio presentation
- business-oriented frontend design

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run locally

```bash
npm install
npm run dev
```

## Notes

This repository is part of my public web portfolio. It is kept as a frontend/design case rather than an actively maintained product.
